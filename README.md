This is my project for week 1 terra
This is my first proper project for hackclub!
How it works:
1. Open the demo link below
2. Press run at the top
3. Select which program you want to use
4. Type the numbers in the 2 boxes (only 1 box for square root) but remember not to type any letters
5. Click submit
6. You will see the result over the submit button


This calculator has 6 inbuilt functions which can be accesed from the main dashboard hub and all of the 6 functions have different colours
